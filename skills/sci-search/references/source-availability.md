# Реальная доступность источников (детали к §4 тела скилла)

Инструменты видят открытый веб. Половина «золотых» баз недоступна — это надо знать
заранее, а не выяснять пятью неудачными запросами.

## Что НЕ откроется

| Ресурс | Что происходит |
|---|---|
| Scopus, Web of Science, ProQuest | подписка, доступа нет вовсе |
| Elsevier / Springer / Wiley / T&F full text | HTTP 403 на `WebFetch` — пейволл, не бот-стенка (§5 тела) |
| ResearchGate, Academia.edu | 403 (антибот) — иногда берётся браузером |
| CERN CDS и часть репозиториев | бот-стенка proof-of-work → решается браузером |
| Многие PDF стандартов и норм | приходят как бинарь — текст не извлекается |
| Sci-Hub и зеркала | не использовать |

Строки «бот-стенка» и часть 403 — **не окончательный отказ**: сначала попробовать
браузер. Окончательны только подписка и пейволл.

## Что работает

| Ресурс | Зачем | Как |
|---|---|---|
| **Crossref API** | метаданные по DOI, поиск | `api.crossref.org/works/<DOI>` |
| **OpenAlex** | замена Scopus по метаданным и цитированиям | `api.openalex.org/works?filter=...` |
| **Unpaywall** | легальная открытая копия статьи | `api.unpaywall.org/v2/<DOI>?email=...` |
| **PMC (PubMed Central)** | ПОЛНЫЙ текст биомед/радиология | `pmc.ncbi.nlm.nih.gov/articles/PMC…` |
| **PubMed** | абстракт + точные реквизиты | `pubmed.ncbi.nlm.nih.gov/<PMID>/` |
| **arXiv** | препринты физики/CS полностью | `arxiv.org/abs/…` |
| **DOAJ** | открытые журналы | `doaj.org` |
| **IAEA Live Chart / NDS** | ядерные данные (T½, β-эндпоинты, γ-линии) | API `nds.iaea.org/relnsd/v1/…` |
| **NNDC ENSDF, LNHB/DDEP** | оценённые ядерные данные, эталон | `nndc.bnl.gov/ensdf/`, `lnhb.fr/nuclides/` |
| **NIST** | константы, сечения, XCOM, X-ray | `physics.nist.gov` |
| **Google Patents, Espacenet** | патенты полным текстом | открыты |
| **eLIBRARY, КиберЛенинка** | русскоязычные статьи (КЛ — открыто) | `cyberleninka.ru` |
| **docs.cntd.ru, meganorm, garant** | тексты ГОСТ/СанПиН | часто открыты в HTML |
| Сайты производителей | datasheet, manuals | обычно открыты |

**Лестница доступа при пейволле** (по порядку, дальше — только если предыдущее не дало):
DOI → Crossref (реквизиты) → Unpaywall/OpenAlex (открытая копия) → PMC/arXiv →
репозиторий университета или автора → абстракт PubMed → честное 📗.

## Прежде чем ставить 📗 — сменить ТРАНСПОРТ, а не только адрес

Отказ инструмента ≠ недоступность документа. `WebFetch` — один способ забрать файл,
и далеко не самый живучий. Прямое скачивание в обход `WebFetch` обязано быть
испробовано до того, как источник объявлен непрочитанным:

```
curl -s -L --max-time 20 -o out.pdf "<URL>" -w "HTTP %{http_code}, size %{size_download}\n"
```

затем разбор локально (`fitz`/`pymupdf`). Работает там, где `WebFetch` не смог.

**Признаки, что упёрся ИНСТРУМЕНТ, а не доступ:**

| Что вернулось | О чём это на самом деле |
|---|---|
| `HTTP 402 Payment Required` на документе организации, которая публикует бесплатно (IAEA, NIST, МАГАТЭ, ВОЗ) | техническая стена прокси/CDN, НЕ коммерческий пейволл |
| `ECONNREFUSED`, таймаут, обрыв | сетевой слой `WebFetch`, `curl` часто проходит |
| «бинарь/не удалось извлечь текст» | PDF пришёл, но не распарсился — качать и читать локально |
| HTML-страница-контейнер сломана (модалка, JS-виджет) | сам документ может лежать рядом отдельным файлом |

**Отдельно — PDF-ссылки из выдачи `WebSearch`.** Если в результатах поиска есть прямая
ссылка на `.pdf`, тянуть НАДО ЕЁ, а не страницу-контейнер, на которой он висит.
Страница может быть сломана, требовать JS, прятать контент за модальным окном — файл
при этом лежит рядом и качается одной командой.

> **Прецедент (29.07.2026, разбор ошибки).** Два документа объявлены непрочитанными,
> оба оказались в свободном доступе. **IAEA-TECDOC-1275**: `WebFetch` дал `402 Payment
> Required` → помечен 📗 «пейволл». На деле IAEA раздаёт TECDOC бесплатно, `curl` берёт
> файл с первой попытки. **Слайды CIEMAT**: страница Indico сломана модалкой выбора
> часового пояса, `get_page_text` и `read_page` возвращали список часовых поясов →
> помечено ⚠️. При этом **прямая ссылка на `NewPhotonEvaporation_v03.pdf` лежала прямо
> в выдаче `WebSearch`** и качалась одной командой — 21 слайд, всё содержимое.
> Отягчающее: в той же сессии приём уже применялся — PDF ETNA у LNHB не дался
> `WebFetch` (`ECONNREFUSED`), но взялся `curl` (HTTP 200). То есть способ был известен
> и сработал, но не был применён к двум другим источникам. **Вывод: лестница транспорта
> проходится ДО пометки уровня, каждый раз, а не когда вспомнилось.**

## Находки контура моделирования (14.09.2026, письмо контура моделирования)

Скилл `sci-search` в `project-folders-registry.md`/`cross-agent-routing.md` без владельца; факты внесены надзорным контуром
как хранителем доктрины, без правки методики самого скилла. Назначение владельца — отдельный вопрос оператору.

- **Europe PMC вместо PubMed** при бот-стенке (HTTP 203, «Cookies must be enabled»):
  `https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=EXT_ID:<PMID>&resultType=core&format=json`.
- **Crossref отдаёт полный реферат** в поле `abstract` у части записей Wiley/AIP; DOI, собранный «по логике» (не из
  списка литературы), сверять по ЗАГОЛОВКУ через `api.crossref.org/works/<DOI>`, не по «200 OK» — известен случай,
  когда такой DOI вёл на другую статью.
- **OSTI** `https://www.osti.gov/servlets/purl/<id>` отдаёт полный PDF работ LLNL/LBNL без пейволла IEEE.
- **ESTAR**: номера материалов брать из `<option value>` страницы, не из памяти (пример ошибки: 176 = гипс, не NaI).
- Проверку границы базы делать запросом ЗА границу, а не по пересказу документации.
- `curl -w "HTTP %{http_code}, size %{size_download}"` обязателен: NEA отдавала 404 с `content_type:
  application/pdf` — по одному коду статуса это не видно.
- **Журнальная версия ≠ препринт** — ключевые числа сверять в обеих (пример: EPJC, гашение «~15%» в препринте →
  «~11%» в журнальной версии).
- `get_page_text` не отдаёт скрытые вкладки — `javascript_tool` с `textContent`/`innerHTML`.
- Chrome по ссылке на `.pdf` скачивает файл в Downloads, `WebFetch` по PDF сохраняет его на диск — при запрете
  скачивания эти пути не применять.
- `WebFetch` не даёт `file:line`; `git clone --single-branch` требует явный refspec; API `compare` GitHub усекает
  хронологию.

## Находки контура моделирования (15.09.2026, письмо контура моделирования, прогон `deep-research` дыра 26)

Факты со слов агентов прогона, контур моделирования их не перепроверял (кроме помеченного «проверено оркестратором»).

- **Browser pane**: Cloudflare у Wiley держится дольше 6 с ожидания, ScienceDirect со второго захода поднимает
  CAPTCHA — издательские страницы этих двух доменов сразу обходить через препринты/Europe PMC, не пытаться
  напрямую.
- **Europe PMC REST** отдаёт аннотации Elsevier (Appl. Radiat. Isot. и др.) дословно, поле `abstractText`.
- **Сводка `WebSearch` может неверно атрибутировать цитату** (наблюдался случай: цитата про GRETINA приписана
  COSI) — решающую цитату всегда искать подстрокой в самом скачанном PDF, не доверять пересказу выдачи.
- Числа из пересказа `WebSearch` — проверять `curl` + grep сырого HTML/PDF (наблюдался случай: величина «50 мм
  свинца» в пересказе приписана не тому изделию, что в источнике).
- **J-STAGE**: таблицы, отрисованные как картинка в PDF, `fitz`/PyMuPDF пропускает как текст — рендерить страницу
  в JPEG и читать глазами.
- **Sci Rep** редиректит на страницу авторизации — копия статьи ищется в PMC, читается `get_page_text`.
- **HTML-версия arXiv**: `curl` + локальная очистка тегов даёт дословную цитату лучше, чем `WebFetch` (та же
  разница, что в правиле 4 брифа — пересказ модели против видимого текста).
- **NIST ESTAR**: POST-запрос с несколькими энергиями, разделёнными пробелом, — `Invalid number`; шаблон таблицы
  ответа разный у элементов (7 колонок) и у соединений (5 колонок), парсер должен различать по типу материала.
- **Форум Geant4 (Discourse)**: JSON без обёртки в HTML — `https://geant4-forum.web.cern.ch/search.json?q=<запрос>`
  и `/t/<id>.json`; короткий запрос из 1-2 ключевых слов даёт более полную выдачу, чем многословный (проверено
  оркестратором на нескольких запросах).
- **Привязка «модели Geant4» к версии физ-листа обязательна**: модель Batič (Клейн–Нишина, поправка 0,54) для
  Comption ниже 20 МэВ в `option4` не используется — там стоит `G4LowEPComptonModel` (проверено оркестратором по
  исходнику физ-листа). Утверждение «Geant4 использует модель X» без указания физ-листа/версии — недостаточно
  для ✅.
- **Класс риска закачки без проверки размера** (см. также правило 5(2) брифа `deep-research`,
  `references/subagent-brief.md`): независимо друг от друга три агента одного прогона скачали один и тот же файл
  arXiv:2411.02606 (149,7–168 МБ по их независимым замерам) при текстовом лимите 50 МБ в брифе прежней редакции —
  текстовый лимит без обязательной команды `curl -sI` агенты не соблюдают. Мера — команда добавлена в бриф
  15.09.2026 надзорным контуром (владение `deep-research` как орфанного скилла по правилу §13).
