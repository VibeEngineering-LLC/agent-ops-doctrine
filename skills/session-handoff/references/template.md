## Отличия для клонированной роли (несколько машин)

Если роль (как Цензор) существует в нескольких копиях на разных машинах —
добавить явно:

```markdown
**Эта копия:** <какая именно — десктоп/ноутбук/др.>
**Маппинг путей к другим копиям:** <например "десктоп C:\Users\<you>\... ↔
ноутбук C:\Users\<you>\...">
```

Без этого поля читающая сессия не может отличить «мой собственный устаревший
план» от «план другой копии той же роли» — реальная ошибка, поймана
09.08.2026 на контуре Цензор (ноутбучный клон принял десктопный
`SESSION-STATE.md` за свой).
