## 2. Публикация демо-страниц — дефолтный метод (§29, НАВСЕГДА, 2026-07-10)

**Зафиксировано оператором 2026-07-10:** «запомни этот метод для демостраниц. используй по умолчанию».

**ИМПЕРАТИВ:** любую самодостаточную демо/витрину (дизайн-макет, отчёт-эксперимент, интерактив) публикую дефолтом в `github.com/VibeEngineering-LLC/demo-web-pages` (public, GitHub Pages) — папкой `<slug>/index.html`, живой URL `https://vibeengineering-llc.github.io/demo-web-pages/<slug>/`. Auth: `gh` как `Verter73`.

Artifact-файл (контент без `<!doctype>/<head>`) ПЕРЕД пушем обернуть в полный документ (разрез по первому `</style>`: title+style→`<head>`, остальное→`<body>`, каркас `lang="ru"`+charset+viewport).

**Гейты:**
1. Секрет-скан файла до пуша (`<имя-клиента>|<ИНН>|<id-хостинг-аккаунта>|<имя-хостинга>|<личная-облачная-папка>|<имя-менеджера-секретов>` → 0 совпадений; приватный проект-агент наружу не идёт, только чистые витрины).
2. `git add` конкретного пути, **НИКОГДА `-A`**.
3. Публикация в public — явная команда оператора на конкретную страницу.
4. **Типографика (раздел ниже): `grep -cE "text-align:\s*justify"` → 0**, и у каждого текстового блока задан предел длины строки.

Метод, код-обёртка, шаги: `<home>\.claude\references\demo-web-pages-publish.md`.

## 3. Типографика — выключка и длина строки (оператор, 2026-08-27, ПОВТОРНОЕ замечание)

**ИМПЕРАТИВ: текст выключается ВЛЕВО, `text-align: justify` не применять никогда.**
Дословно: «и опять выравнивание текста по ширине!!!! сколько можно? самообучайся!».
Без переносов выключка по формату рвёт строки «реками» пробелов, тем сильнее, чем
длиннее слова — а русские термины длинные.

**Вторая половина требования — ДЛИНА СТРОКИ, и практически она важнее.** В инциденте
27.08 `justify` в CSS не было вовсе: абзацы врезок шли во всю ширину листа (>1100 px)
и читались как выключка по формату. Ограничивать ширину надо у ВСЕХ текстовых блоков,
а не только у вводного абзаца — врезки, списки и подписи забываются первыми.

Готовый блок, вставлять в каждую страницу:
```css
body,p,li,td,th,figcaption,caption{text-align:left}
p,li{max-width:78ch;text-wrap:pretty}
.note p,.warn li,.warn p{max-width:74ch}   /* врезки — про них и забыл */
```
Правило для числовых колонок (`th,td{text-align:right}`) ставить ПОСЛЕ этого блока,
иначе числа съедут влево.

**Санитизация публичных страниц** (действует и здесь): не упоминать реальные имена агентов и контуров, имена приватных скиллов (сетевых, секретарских, финансовых, поисковых по личным документам, проектных), адреса локальной сети, имена и контакты третьих лиц, детали межсессионного канала и сетевой инфраструктуры.
