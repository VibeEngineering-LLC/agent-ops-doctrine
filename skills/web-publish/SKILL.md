## 2. Публикация демо-страниц — дефолтный метод (§29, НАВСЕГДА, 2026-07-10)

**Зафиксировано оператором 2026-07-10:** «запомни этот метод для демостраниц. используй по умолчанию».

**ИМПЕРАТИВ:** любую самодостаточную демо/витрину (дизайн-макет, отчёт-эксперимент, интерактив) публикую дефолтом в `github.com/VibeEngineering-LLC/demo-web-pages` (public, GitHub Pages) — папкой `<slug>/index.html`, живой URL `https://vibeengineering-llc.github.io/demo-web-pages/<slug>/`. Auth: `gh` как `Verter73`.

Artifact-файл (контент без `<!doctype>/<head>`) ПЕРЕД пушем обернуть в полный документ (разрез по первому `</style>`: title+style→`<head>`, остальное→`<body>`, каркас `lang="ru"`+charset+viewport).

**Гейты:**
1. Секрет-скан файла до пуша (реальные имена клиентов/брендов, ИНН, номера хостинг-аккаунтов, пароли к панелям управления → 0 совпадений; приватный проект-агент наружу не идёт, только чистые витрины).
2. `git add` конкретного пути, **НИКОГДА `-A`**.
3. Публикация в public — явная команда оператора на конкретную страницу.

Метод, код-обёртка, шаги: `C:\Users\<you>\.claude\references\demo-web-pages-publish.md`.

**Санитизация публичных страниц** (действует и здесь): не упоминать имена приватных контуров/агентов, реальные PII (ФИО, номера, адреса), локальные IP-диапазоны домашней/офисной сети, названия и детали любых опсек-чувствительных или финансовых внутренних проектов.
