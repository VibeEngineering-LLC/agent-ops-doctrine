# Доменные модули поиска

Вставляются в ТЗ субагента вместе с блоком `subagent-brief.md`. Смысл модуля — снять
с агента выяснение того, что уже известно контуру: грабли, специфичные для типа
вопроса.

**Карта доступности баз здесь НЕ дублируется** — она в `sci-search` §4 (что открыто,
что за пейволлом, что решается браузером, лестница обхода). Дублировать её означало бы
завести вторую копию, которая разойдётся с оригиналом при первом же обновлении, и
агент получит устаревшую. Субагент грузит `sci-search` нулевым ходом и берёт карту
оттуда; здесь — только доменная надстройка.

Оболочка: команды ниже даны для **git-bash**. В PowerShell `base64` отсутствует,
эквивалент — `[Text.Encoding]::UTF8.GetString([Convert]::FromBase64String($c))`.

---

## Модуль 1. Научные статьи

**Порядок обхода:** DOI → Crossref (реквизиты) → Unpaywall/OpenAlex (открытая копия) →
PMC/arXiv → репозиторий университета или личная страница автора → абстракт PubMed →
честное 📗. Адреса API — `sci-search` §4.

⚠️ Точные параметры запросов к OpenAlex и Unpaywall в контуре не зафиксированы:
прочитать документацию API первым ходом, **не угадывать синтаксис фильтров**.
Unpaywall требует поле `email` — брать значение из задания, не подставлять найденный
в окружении адрес оператора.

**Грабли домена:**
- Ключевые числа лежат в таблицах раздела результатов, не в абстракте. Пересказ
  абстракта, выданный за содержимое статьи, — типовой провал.
- Год публикации ≠ актуальность: смотреть, нет ли выше по цитированиям опровержения
  или отзыва (retraction).
- Препринт и рецензированная версия расходятся: цитировать ту, которую читал, и
  говорить, какую именно.

## Модуль 2. Стандарты и нормативы

**Обязательно для КАЖДОГО стандарта:**
1. Действует / заменён / отменён — и **чем именно** заменён.
2. Область действия: ГОСТ 7.1-2003 в РФ вытеснен ГОСТ Р 7.0.100-2018, но продолжает
   действовать в СНГ — типовая ловушка.
3. Редакция: ссылка на номер без года — источник половины расхождений.

**Грабли домена:**
- Превью-площадки (iTeh и подобные) дают первые страницы: оглавление и термины.
  Нужное в клаузе 7, а видны 1–4 — это 📗, сколько бы страниц ни отрендерилось.
- **Символы сравнения бьются при извлечении текста из PDF нормативов.** Замеренный
  случай: в `JCGM_100_2008_GUM.pdf` текстовый слой систематически отдаёт «≤» как
  латинскую «u», «≥» как «W» — подтверждено в клаузах C.2.27 и C.2.28 сверкой
  координат слов (верификатор контура, 01.08.2026; запись —
  `claude-skills/terminology/data/domains.yaml`, комментарий к домену statistics).
  Формулы и неравенства, снятые сырым `get_text()`, проверять рендером страницы.
- Номер ГОСТ по памяти модели = класс выдуманного DOI. Только по найденному тексту.

## Модуль 3. Ядерные и физические данные

**Базы:** IAEA Live Chart / NDS, NNDC ENSDF, LNHB/DDEP, NIST — адреса в `sci-search` §4.

⚠️ Точные параметры REST-запросов к NDS в контуре не зафиксированы — прочитать
документацию API, не собирать URL по догадке.

**Главная грабля домена — расхождение оценённых баз.** ENSDF, LNHB и KAERI дают
разные значения одной величины: замеренный случай — E_max ²³⁴ᵐPa, LNHB 2,269 МэВ
против ENSDF 2,29 и KAERI 2,271 (`sci-search` §1, там же прецедент целиком). Это не
ошибка чьей-то стороны, а разные оценки. Показывать обе, называть рекомендованную,
никогда не усреднять.

`402 Payment Required` от IAEA или NIST — сломанный прокси, а не цена: эти
организации публикуют бесплатно.

## Модуль 4. Патенты

**Базы:** Google Patents и Espacenet — открыты, полный текст; Роспатент — РФ-заявки.

**Что извлекать помимо формулы изобретения:** раздел «уровень техники» — там
перечислены отвергнутые решения с причинами, готовый материал для направления
«по отрицанию».

**Грабля:** патент описывает заявленное, а не работающее. Наличие патента не
подтверждает, что решение доведено до продукта или воспроизводимо.

## Модуль 5. Оборудование и datasheet

**Жёсткое правило домена:** вендорский блог и маркетинговая страница — источник
уровня D, его datasheet — уровня C. «До 30 % точнее» с лендинга в выводы не идёт.

**Число из datasheet берётся только с условиями измерения** — без них характеристика
бессмысленна. Фиксировать: ревизию документа, дату, условия (температура, геометрия,
время набора), границы применимости, отличие типового значения от гарантированного.

**Рынок и доступность** (если вопрос про выбор, а не про физику): наличие,
актуальность модели, статус EOL, преемник снятой позиции, дистрибьюторы. Каталоги
дистрибьюторов — тяжёлые SPA: если вернулась пустая страница, редирект или челлендж,
это стена, а не отсутствие товара — идти браузером (`subagent-brief.md`, правило 5).
Цены и сроки поставки помечать датой обращения обязательно, они живут недели.

## Модуль 6. Открытый код и репозитории

**Реквизиты — только через API, не из текста статей и не из README:**

```bash
gh api repos/OWNER/NAME --jq '{stars:.stargazers_count,forks:.forks_count,license:.license.spdx_id,pushed:.pushed_at,archived:.archived}'
```

Дерево файлов и содержимое:

```bash
gh api repos/OWNER/NAME/git/trees/HEAD?recursive=1 --jq '.tree[].path'
gh api repos/OWNER/NAME/readme --jq '.content' | base64 -d
gh api repos/OWNER/NAME/contents/<путь> --jq '.content' | base64 -d
```

**Обязательные проверки, пропуск любой обесценивает находку:**

1. **Лицензия.** «Публичный репозиторий на GitHub» ≠ «открытая лицензия». `license:
   null` означает: права не предоставлены, использовать нельзя, сколько бы звёзд ни
   стояло. Проверять и полем API, и листингом корня — файл LICENSE иногда есть при
   пустом поле и наоборот. Живой пример: у `anthropics/skills` при 166 тыс. звёзд
   поле `license` пустое.
2. **Живость.** `pushed_at` и `archived`. Заброшенный на год репозиторий с тысячей
   звёзд — не решение, а памятник.
3. **Содержимое против описания.** Описание репозитория — реклама автора, не факт.
   Замеренный случай (05.08.2026): в `199-biotechnologies/claude-deep-research-skill`
   файл с именем `verify_citations.py` в собственном докстринге признаёт, что сверяет
   «DOI resolution (via doi.org)», «Basic metadata matching (title similarity, year
   match)» и доступность URL — то есть реквизиты, не содержание. Имя обещало
   верификацию, код делал ровно дефект citation-green. Читать код, а не имя.
4. **Заявления о превосходстве.** «Outperforms X in quality» без ссылки на бенчмарк —
   утверждение автора, помечается ⚠️, в выводы не идёт.
5. **Звёзды — не качество.** Метрика популярности репозитория на GitHub, ничего
   более. Указывать как реквизит, не как аргумент.

**Безопасность.** Официальный каталог плагинов предупреждает прямо
(`github.com/anthropics/claude-plugins-official`, README, обращение 05.08.2026,
дословно):

> «Make sure you trust a plugin before installing, updating, or using it. Anthropic
> does not control what MCP servers, files, or other software are included in plugins
> and cannot verify that they will work as intended or that they won't change.»

Отсюда правило контура: рекомендация «поставить» выдаётся только после чтения кода,
лицензия проверяется до установки, а не после.

## Модуль 7. Русскоязычные источники

**Базы:** КиберЛенинка (открыта, полные тексты), eLIBRARY (часть открыта),
`docs.cntd.ru` и `meganorm` (нормативы), сайты диссоветов и РГБ (диссертации).

**Главная грабля:** `WebSearch` ориентирован на США, русскоязычная выдача заметно
беднее. RU-запрос гоняется **не как перевод EN-запроса, а как самостоятельный
заход**: другая терминология, другие синонимы, другие исторические названия. ГОСТ
находится по-русски и почти никогда по-английски; physics — наоборот.

**Терминология:** до построения RU-запроса свериться со словарём контура —
`python C:\Users\<you>\.claude\skills\terminology\scripts\lookup.py <термин>`.
Разговорный синоним вместо канонического термина рушит выдачу, изобретённый термин
рушит и выдачу, и отчёт.

## Модуль 8. Датасеты, статистика, геоданные

**Что искать:** открытые репозитории данных (Zenodo, Figshare, Dryad), порталы
статистики ведомств, геопривязанные наборы. Точные адреса и условия доступа в контуре
не зафиксированы — устанавливать поиском, помечая уровень.

**Обязательные проверки набора данных:**
1. **Лицензия и условия использования** — как с кодом: публичная доступность ≠ право
   переиспользования. CC-BY требует атрибуции, CC-BY-NC запрещает коммерческое.
2. **Версия и дата среза.** Датасет без версии нецитируем: через полгода по той же
   ссылке лежит другое.
3. **Методика сбора.** Число из набора без описания того, как оно измерено, — то же,
   что число из datasheet без условий измерения.
4. **Полнота.** Пропуски, отфильтрованные записи, изменённая методика в середине
   ряда — искать в описании, а не предполагать однородность.

**Грабля:** агрегатор перепубликует чужой набор под своим именем. Ссылаться на
первичного издателя, не на агрегатор, — тот же принцип, что первоисточник против
пересказа.
