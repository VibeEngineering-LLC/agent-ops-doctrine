# Шаблоны записей журнала инцидентов

Два файла, две нумерации. Копировать блок целиком, заполнять все поля.
Поле, по которому нечего сказать, — писать «нет»/«не проверено», НЕ удалять: пустое поле
само по себе диагноз (например, «Как пойман: случайно» = дыра в контроле).

---

## Шапка файла `work-incidents.md` (создать один раз)

```markdown
# <Контур> — Журнал РАБОЧИХ инцидентов

Сбои собственной работы агента: процессные провалы, нарушения правил, silent-fail,
false-green, расхождение заявленного и фактического. Баги продукта — НЕ сюда,
они в `project-incidents.md` соответствующего проекта (скилл `incident-log`).

Правила ведения: скилл `incident-log`. Нумерация сквозная `W-NNN`.
Anti-hallucination: каждая запись ссылается на file:line / SHA / вывод команды / verbatim ошибки.

---

## Записи
```

## Шапка файла `project-incidents.md` (создать один раз)

```markdown
# <Проект> — Журнал ПРОЕКТНЫХ инцидентов

Дефекты продукта: код, прошивка, расчёт, конфиг, регрессии. Процессные провалы агента —
НЕ сюда, они в `work-incidents.md` контура (скилл `incident-log`).

Правила ведения: скилл `incident-log`. Нумерация сквозная `P-NNN`.

---

## Записи
```

## Шаблон записи — РАБОЧИЙ инцидент

```markdown
### W-NNN — <однострочный заголовок: суть, читаемая отдельно от тела>
- **Дата / контур**: YYYY-MM-DD / <контур>
- **Класс / подкласс**: РАБОЧИЙ / <подкласс по references/taxonomy.md>
- **Внешний симптом**: <что было видно ДО разбора — то, по чему это опознается в следующий раз>
- **Error verbatim**: <точный текст ошибки/расхождения; если сбой молчаливый — так и написать>
- **Root cause**: <ПОЧЕМУ, не что. «Упало» — не причина>
- **Как пойман**: <чем именно обнаружен: штатной проверкой / случайно / оператором>
- **Цена**: <что потеряно: прогон, время, неверный доклад оператору, испорченные данные>
- **Корректирующая мера**: <конкретная, с файлом и местом; по лестнице мер — самая сильная доступная>
- **Проверка меры**: <чем подтверждено, что работает: прогон/тест/чтение файла>
- **Сканирование класса**: <проверены ли остальные места с тем же дефектом; сколько найдено>
- **Урок уровня доктрины**: <да/нет; если да — куда поднят и кому разослан>
- **Owner / status**: <контур> / **OPEN | CLOSED-fixed | CLOSED-analyzed | WONTFIX**
```

## Шаблон записи — ПРОЕКТНЫЙ инцидент

```markdown
### P-NNN — <однострочный заголовок>
- **Дата / проект / компонент**: YYYY-MM-DD / <проект> / <файл, модуль, прошивка, версия>
- **Класс / подкласс**: ПРОЕКТНЫЙ / <подкласс по references/taxonomy.md>
- **Внешний симптом**: <что наблюдалось: неверное число, зависание, краш, тихо неверный результат>
- **Воспроизведение**: <точные шаги/вход, на котором проявляется; «не воспроизводится» — тоже факт>
- **Error verbatim**: <лог, stacktrace, дамп, расхождение значений>
- **Root cause**: <file:line + механизм>
- **Как пойман**: <тест / прогон / оператор / внешний отчёт>
- **Затронутые данные**: <есть ли уже посчитанные/выданные результаты, которые теперь под сомнением>
- **Исправление**: <что изменено, где; SHA коммита если есть>
- **Проверка исправления**: <тест/прогон, подтверждающий; регресс-тест добавлен?>
- **Сканирование класса**: <есть ли тот же дефект в других местах кодовой базы>
- **Owner / status**: <контур-владелец зоны> / **OPEN | CLOSED-fixed | WONTFIX**
```

## Пример заполнения (реальный, W-класс)

```markdown
### W-001 — Silent-fail хука: stdin не форсирован на UTF-8, снапшот вышел пустым
- **Дата / контур**: 2026-08-15 / censor
- **Класс / подкласс**: РАБОЧИЙ / silent-fail (exit-код солгал)
- **Внешний симптом**: хук вернул exit=0 и `{"suppressOutput": true}`, файл снапшота на диске
  0 байт, `latest.json` не обновлён — никакого признака сбоя
- **Error verbatim**: `UnicodeEncodeError: 'utf-8' codec can't encode character '\udc98' in
  position 284: surrogates not allowed` (получен только после патча debug-копии; штатно
  проглатывался широким except)
- **Root cause**: форсирован UTF-8 только на `sys.stdout`, не на `sys.stdin`; на cp1251-консоли
  кириллица в `cwd` стала суррогатами, `open(...,"w")` обнулил файл, `f.write()` упал
- **Как пойман**: проверкой файла на диске после «успешного» прогона (§31.A.2, класс «Состояние»),
  не поверив коду возврата. Штатной автопроверки не было — дыра в контроле
- **Цена**: механизм молча не работал бы при каждом сжатии контекста; обнаружено на первом же
  живом срабатывании
- **Корректирующая мера**: (1) `sys.stdin.buffer.read().decode("utf-8", errors="replace")` в обоих
  хуках скилла; (2) правило #ENC-1 в `CLAUDE.md` §2 + тело в `references/windows-encoding.md`
- **Проверка меры**: полный цикл — снапшот 5379 байт, кириллица читаема, `last-prompt` собраны,
  postcompact вернул верный путь
- **Сканирование класса**: проверены ВСЕ хуки в `~/.claude/hooks/` — найдено ещё 5 с тем же
  дефектом, худший `session_start_hook.py` (сверяет cwd с маркером «Цензор» → контур молча
  не распознавался). Все переведены на байтовое чтение, прогон подтверждён
- **Урок уровня доктрины**: да — #ENC-1 в глобальном CLAUDE.md §2, касается всех контуров
- **Owner / status**: censor / **CLOSED-fixed**
```
